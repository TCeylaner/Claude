# My first application

Repository for my apps. Each app lives in its own folder and is deployed as its own Vercel project (Root Directory = the folder).

| App | Folder | Vercel project |
|-----|--------|----------------|
| Range Management (range builder, targets, sell-in, compare) | `range-management/` | `range-management` |

To add an app: create a new folder with its files, then in Vercel use Add New → Project → import this repo and set Root Directory to the new folder.
